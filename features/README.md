# Planned features

These are proposals, not built yet. Each file covers one feature: current state, why it might be worth doing, an implementation sketch, an effort estimate, and open questions to decide before building.

- [01-authentication.md](01-authentication.md) — replacing the current shared-password gate with per-user access (invite codes, email magic-link, or OAuth)
- [02-richer-taste-profile.md](02-richer-taste-profile.md) — showing your actual top-rated movies as clickable cards, plus more profile stats
- [03-discovery-expansion.md](03-discovery-expansion.md) — a separate "Explore" mode for trending/genre-gap picks not tied to your rating history
